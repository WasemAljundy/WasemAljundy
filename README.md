# 👨‍💻 About Me

I’m **Wasem Aljundy**, a Software Engineer and Mobile Application Developer specializing in building high-quality, scalable, and maintainable applications using **Flutter and Dart**.

I develop cross-platform applications for **Android and iOS**, with practical experience in application architecture, REST API integration, Firebase services, local databases, state management, responsive UI implementation, and publishing production-ready applications.

Alongside Flutter development, I have experience building native Android applications using **Java, XML, Room, Retrofit, and MVVM**, as well as working with backend technologies and relational databases.

I care about more than making an application work. I focus on writing clean code, creating smooth user experiences, organizing projects professionally, and building solutions that can grow and remain maintainable over time.

* 📱 Specialized in Flutter and cross-platform mobile application development
* 🤖 Experienced in native Android development using Java and XML
* 🔥 Experienced with Firebase, REST APIs, authentication, notifications, and real-time data
* 🧱 Interested in clean architecture, scalable project structures, and reusable components

* 🚀 Continuously improving my knowledge through real projects and technical challenges
* 🤝 Open to freelance projects, remote opportunities, and professional collaborations

## 🧠 Development Principles

> Clean code is not only about making software work today.
> It is about making it understandable, testable, scalable, and maintainable tomorrow.

* Write readable and reusable code
* Keep business logic separated from the user interface
* Build features with scalability in mind
* Handle loading, error, empty, and success states properly
* Prioritize performance and user experience
* Test important behavior before shipping
* Document decisions that affect future development
